## 跨境专线报价由什么决定？先把计费方式弄清楚

同一条"深港"或"沪港"线路，报出两个差一倍的价格，多半不是有人乱报价，而是两个人的计费方式根本不同。影响价格的主要是这几件事：

- **线路类型**：IEPL（国际以太网专线）、IPLC（国际专线电路）和 IX（通过互联网交换中心/云网络对接的优化线路）成本不同。Mkcloud 的产品资料里，广港 IEPL、深港 IX、厦港高防 IPLC 的端内参考延迟都是 1~2ms，沪港 IPLC 是 21ms，沪日 25~28ms，沪美 124~134ms。方向越远、链路成本越高，价格通常越贵。
- **共享还是独享**：共享款按"峰值带宽 + 月流量"计费，比如 200Mbps 峰值、每月 1TB 流量，流量按上行加下行双向统计，用完就暂停，需要买流量重置或补差价升级；独享款按"固定速率 + 不限流量"计费，比如 5Mbps 独享、不限流量。两者的"带宽"数字没法直接比大小。
- **接入条件**：直连款绑定一个连入省份；IX 款不限省份，但要求你已有支持云厂商（如阿里云、腾讯云等）的云网络，云前置机的费用要自己算进总成本。
- **附加服务**：默认套餐不含 SLA，需要可用性承诺、路由定制或更高防护参数时，要单独询价。

一句话：报价至少要拆成"线路方向 + 带宽模式 + 流量额度 + 接入成本"四层来看，只比一个 Mbps 数字没有意义。

### 独享带宽款的计费逻辑

独享款不看流量，看固定速率。以沪港为例，5Mbps 独享月付 388 元起，10M、20M、50M、100M 逐档往上加价，100M 独享去到每月数千元。它解决的是"持续跑"的问题：连续几个小时传素材、跑授权 API、长时间推流，这类任务对持续速率的要求高于瞬时峰值。

独占大带宽是另一回事：广东三线 IEPL 有 200M–2000M 独享档，带 300G 高防，量大可以议价；厦港高防 IPLC 默认含 100Gbps 防护，200M 档 6000 元/月，1G 档 24000 元/月，5G 档 110000 元/月。这是给游戏、金融、大促期电商这类真需要抗攻击的业务准备的，普通卖家不用看到这个数字就觉得自己预算不够。

## 共享还是独享？拿沪港两条入门套餐算笔账

官方知识库给的这对入门套餐，是理解两种计费方式最直观的例子：

- **共享入门，288 元/月**：1 核 2G 内存、20GB 硬盘、200Mbps 峰值、1024GB 月流量（双向统计）。季付 864 元、年付 3456 元。峰值高，但持续速度不保证跑满，流量用完会暂停。
- **独享入门，388 元/月**：2 核 4G 内存、40GB 硬盘、5Mbps 独享、不限流量。速率永远稳定在 5Mbps，但没有流量焦虑。

怎么选，取决于你的任务形状。每天在店铺后台上传一批图片、偶尔开视频会议，属于"短时突发"型，共享的 200Mbps 峰值用起来更舒服，1TB 流量对图文后台操作也相当耐用。反过来，如果要挂着一整天的数据同步、持续从国内往海外服务器传大文件，5Mbps 独享按 625KB/s 左右的持续速率跑，不怕高峰期掉速，388 元买的就是"可预期"。

还有个容易踩的坑：官方明确说共享与独享"不决定账号能否通过平台审核"，带宽模式和你店铺账号的安全性没有关系，别为这个多花钱。

## 套餐之外，预算里容易被漏掉的四项成本

只按套餐标价做预算，实际支出往往会高出截算。这几项要提前算进去：

1. **云前置费用**（仅 IX 款）：深港 IX、沪港 IX、沪日 IX 不限连入省份，但必须通过支持的云厂商网络接入，深圳和上海入口分别限定了云厂和地域范围。你已有的云服务器不一定满足条件，租用前置机的费用要加进总成本。预算有限的话，直连款（绑定一个连入省份，可切换）省掉这笔钱。
2. **流量重置 / 补差价**：计量型套餐超量后暂停服务，可以自助购买流量重置，或者提工单补差价升级到更大档位。
3. **SLA 与定制服务**：默认无 SLA，没有赔付条款和固定故障恢复时长承诺。企业采购若需要可用性保障，先询价再下单，别把产品描述当成 SLA。
4. **变更成本**：升降级都要走工单，而且降级到更低价格套餐时差价不退。首月不确定用量的话，从小档位开始比买大档位再降级更划算。

退款政策也要看清楚：仅质量问题支持退款，需要在工单里提交具体延迟、速度数据等证据，由商家审核判断；开通后不支持更换到其他地域。它是"不是无条件试用"的产品，下单前把接入条件确认好，比事后扯皮省事得多。

## 按业务场景对号入座

报价只是数字，落到场景里才知道该买哪条线。结合官方选型资料：

- **美区独立站 / 亚马逊后台**：看美国方向的实际访问质量，选沪美；用量小从 100GB 档起步即可，后台操作吃不了多少流量。
- **华南团队 / 广深卖家**：本地入口匹配最重要，广港 IEPL 端内延迟 1~2ms，广东多运营商入口可选，图文素材上传体验最稳。
- **做日本平台、日本站群**：沪日 25~28ms，日本方向的访问和客户端测试都够用。
- **上海 / 长三角到香港**：沪港共享按月流量选档，持续传输选独享；已有云网络的可以对比沪港 IX，2TB 档 198 元/月比 IPLC 独享便宜不少。
- **已经有阿里云、腾讯云等服务器**：深港 IX 或沪港 IX 优先，158 元起的入门价是全站最低，但要先核对云厂和地域是否在支持范围内。
- **直播推流、易受攻击的业务**：厦港 / 泉港高防 IPLC，独享带宽加 100Gbps 防护，代价是 6000 元/月起步。
- **只需要国内出站优化**（如部分 API 访问组合）：上海 CN2 是国内优化产品，动态 IP，不能当海外出口用，别买错。

买之前最好用最便宜的一条线测试真实路径，官方自己也在文档里提醒：端内延迟不等于你本地到目标网站的全程耗时， geographical 位置相近不代表路由更快。

## 下单前值得确认的几件事

Mkcloud 的购买流程本身不复杂：产品页选套餐，现货通常自动开通，官方口径约 1 分钟，实际受支付和系统安装影响。但这几件事最好在付款前过一遍：

- 需要国内手机号实名认证，企业用户提前准备好。
- 直连款绑定一个连入省份，入口只允许该省份 IP 连入；异地团队先核对接入限制再下单，绑定后期可以自行切换。
- 每台 VPS 分配 1 个独立入口 IP 和 1 个独立出口 IP，出口只用于向外访问，不支持外部连入——也就是说不能拿来部署公开网站、支付回调或游戏服务端。
- 出口是服务器 IP，不保证原生、住宅属性或流媒体解锁，独享 IP 也不等于平台账号绝对不被限制。
- 支持重装系统；快照、备份不在产品能力清单里，重要数据自己做好备份。

## 常见问题

**跨境专线是不是一定比普通 VPS 贵很多？**
没有固定倍数。专线贵在跨境路径、独立入口出口 IP 和带宽约定，和普通 VPS 比要放到相同口径下看。Mkcloud 的共享款 158~228 元/月起，和一台中端普通 VPS 加专线属性的组合相比并不离谱。

**买了专线能加速买家打开我店铺的速度吗？**
不能。Mkcloud 的出口不支持外部连入，买家访问你店铺走的是托管和 CDN 那条路，和这条专线无关。它优化的是你自己操作后台、上传素材、调用授权 API 这一侧的体验。

**能保证我的店铺账号不被封吗？**
不能。官方资料写得很直白：网络只是使用环境的一部分，账号状态取决于平台规则、身份、设备和行为因素。独享 IP 是网络资源，不是护身符。

**历史优惠码还能用吗？**
官方活动回顾里出现过的优惠码（如 MK-8.8、MK-7.8、IXCLOUD 等）对应的活动均已结束，不要按历史折后价做预算。下单时可以在购物车试试当期是否有循环优惠码，以结算页结果为准。
